# Corner-Grocer-Tracker
C++ Program that tracks produce sales for a grocery store

For this project, I was instructed to write a small program to read an input file. The file contained every produce item that was purchased at a grocer. The program reads the files created to a map counting the frequency of each produce item and saves that information. Then it provides the user with a few ways of analyzing the data. I think my input validation and my menu loop went particularly well. I think the code could be enhanced by creating a base class and then a derived Produce item class. This would allow the user to use the same program to track other departments' sales as well. The most challenging part of the project for me was how to store the items and their counts. I originally thought a vector would be most appropriate, but soon found out the difficulty and complexity of executing a loop to count each item's frequency of purchase. I ultimately went with a map, which was recommended in the first place, and that made coding the counting loop much simpler and more efficient. The skills this project helped me sharpen were planning code ahead of time. If I had thought more ahead and worked out the logic of the counting loop, I could have saved some time when switching from using a vector to a map. This project also helped me practice my file input and output code-writing skills. Something I wasn't fully confident in before writing this program. I did my best to make this code readable by limiting the code as much as I could without sacrificing too much functionality. I also tried to limit as much code as I could in the main program file and put as much in functions to allow for future adaptability and support the maintenance of the code as well.
